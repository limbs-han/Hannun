# 깃랩-지라 연동 안내

보드는 깃랩과 자동으로 연동해서 아래 흐름대로만 하면 티켓이 알아서 움직입니다.

---

## 1. **브랜치 생성**

- 형식: `prefix/이슈키-자유` (예: `feat/S15P21E105-59-lsh-filter`)
- 브랜치명에 **이슈 키(대문자)** 만 포함되면 연동. prefix와 뒷부분은 자유
- 지라 이슈의 "브랜치 만들기" 버튼을 써도 되고, 깃랩·로컬에서 직접 만들어도 됨
- 시작 브랜치는 자기 파트 dev (`front/dev`, `back/dev`, `data/dev`)
- 브랜치가 생기면 티켓이 자동으로 **진행 중**으로 처리

## 2. **MR 생성 → 머지**

- 대상: 자기 파트 dev
- 설명의 `Closes S15P21E105-` 에 번호 채우기
- 머지되는 순간 티켓 자동 **완료** 처리

## 3. 새 작업 이슈를 만들 때

- 유형 "작업", 상위 항목 = 소속 에픽, 담당자 = 본인
- "연결된 업무 항목"에서 **relates to로 소속 스토리 연결**
- 작업 이슈 만들고 `사지한`에게 **알리기**
