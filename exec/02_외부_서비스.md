## 자체 호스팅이라 외부가 아닌 것

혼동을 막기 위해 적는다. 아래는 우리 EC2 안에서 돌고 밖에 계정이 없다.

- Pinpoint (APM) — A의 `~/pinpoint` compose. BE 앱 에이전트 3.1.0이 A의 collector로 전송
- Prometheus·Grafana·Pushgateway — B의 compose. Grafana 로그인은 compose의 `GF_SECURITY_ADMIN_*`
- Kafka·MySQL·Redis — B의 compose
- Jenkins — B 호스트 패키지

## 재구축 시 새로 받아야 하는 것

1. EC2 두 대의 pem 키(SSAFY 지급)
2. GitLab 접근 토큰 → Jenkins Credentials `gitlab-token`으로 등록
3. Let's Encrypt 인증서 → `certbot --nginx -d <도메인>` (도메인이 바뀌면 nginx conf의 `server_name`·인증서 경로도 함께)
4. 빅카인즈 데이터가 필요하면 회원 계정 (실시간 서비스에는 불필요)
